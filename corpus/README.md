# Reference corpus

The original hospital notebook expects orange_book.pdf and ashp_guidelines.pdf. Neither PDF was included in the attachments. Obtain authorized copies of the original documents and place them here or in the configured Drive corpus folder.

The saved Orange Book excerpts identify the 45th/2025 edition. The precise ASHP guideline title and edition are not recorded in the supplied notebook. Different editions, extraction behavior, or files can change the saved 6,383-passage count.

Official sources:

- [FDA Orange Book](https://www.fda.gov/drugs/drug-approvals-and-databases/approved-drug-products-therapeutic-equivalence-evaluations-orange-book)
- [FDA Orange Book Preface](https://www.fda.gov/drugs/development-approval-process-drugs/orange-book-preface)
- [Qwen2.5-1.5B-Instruct model card](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct)

No third-party reference PDFs or model weights are redistributed in this repository.
