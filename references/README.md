# Supplied reference demonstration

concussion_rag_demo.ipynb is the separate BA840 demonstration provided with the project files. It illustrates LLM-only, direct retrieval, and RAG using CDC pages, sentence embeddings, FAISS, and Qwen. It is retained as reference material rather than presented as hospital-project implementation or included in the hospital's evaluation counts.

The file is copied unchanged. Its installed packages and external web/model sources may require a GPU, network access, and adjustments for current versions. Its medical triage examples are educational demonstrations, not a clinical service.
